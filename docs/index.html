What is Rebase?

Rebase is an experimental framework for building web interfaces. It combines JavaScript, HTML and CSS in .rebase components while keeping the runtime deliberately small.

Components

<script>
const title = "Hello, Rebase.";

function handleClick() {
  console.log("clicked");
}
</script>

<main>
  <h1>{title}</h1>
  <button on:click="handleClick">Click</button>
</main>

<style>
main { font-family: system-ui; }
</style>

Reactive primitives

Use state, computed, effect and watch for small reactive systems.

const count = state(0);
const doubled = computed(() => count.value * 2, [count]);

effect(() => {
  console.log(doubled.value);
}, [doubled]);
