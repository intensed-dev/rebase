Rebase is a compiler-first framework for building web interfaces with JavaScript, HTML and CSS.

Get started

What is Rebase?

Rebase explores a Vue/Svelte-style single-file component model with a compiler-first architecture. The project is experimental and the API is intentionally small while the architecture is being developed.

Single-file components

<script>
const title = "Hello, Rebase.";
</script>

<main>
  <h1>{title}</h1>
</main>

<style>
h1 { font-family: system-ui; }
</style>

Compile a component, then mount the generated component in the browser.

Current API

  • compile()
  • compileFile()
  • mount()
  • component()
  • .rebase single-file components
